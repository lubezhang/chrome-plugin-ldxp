要点概览

扩展不设置开发者服务器，不投放广告，也不使用分析或追踪工具。数据主要保存在你的 Chrome 扩展存储中；当你主动查询订单、读取卡密、完成人机验证或确认下单时，必要数据会从你的浏览器直接发送给 WZYP 网站及其指定的验证服务。

1. 适用范围

本政策适用于“链动小铺助手”Chrome 扩展。扩展仅在 wzyp.cn 及其子域名页面上运行，用于整理页面中的商品、查询订单、查看卡密，并在订单确认页面自动填写用户保存的信息。

本政策不适用于 WZYP 网站本身或其他第三方服务。你在这些服务上的活动仍受相应服务自身条款与隐私政策约束。

2. 我们处理哪些数据

功能偏好 是否隐藏缺货商品、商品排序方式，以及是否长期记住订单安全密码。
订单查询信息 你输入的联系方式；在 WZYP 接口要求时，订单查询也可能处理并发送安全密码；使用卡密查看或自动填写功能时，也可能处理安全密码。
验证信息 你输入的人机验证码、WZYP 返回的验证码上下文和临时验证票据。
页面与订单内容 当前 WZYP 页面中的商品名称、价格、库存状态，以及查询返回的订单号、商品信息、状态、金额、时间与卡密。扩展仅为展示和操作这些内容而临时处理它们。

扩展不会主动收集你的浏览历史，也不会读取 WZYP 域名之外的网页内容。扩展不收集支付卡号、身份证件、精确位置、通讯录、麦克风或摄像头数据。

3. 数据如何使用

  • 在 WZYP 商品页面中识别商品卡片，按价格排序，并根据你的选择隐藏缺货商品。
  • 在订单确认弹窗中，将已保存的联系方式与安全密码填入仍为空白的对应字段；扩展不会覆盖你已经输入的内容。
  • 在你打开订单功能后，使用联系方式和临时验证票据向 WZYP 查询匹配订单；在 WZYP 接口要求时，订单查询也可能处理并发送安全密码。
  • 在你查看已付款订单卡密时，将订单号及你提供的安全密码发送给 WZYP 订单接口。
  • 在你点击复制时，把所选卡密写入系统剪贴板。

扩展不会使用这些数据建立用户画像，不会用于广告投放，也不会出售、出租或以其他方式交易你的个人信息。

4. 数据存储与保留

本地扩展存储

商品筛选和排序偏好、联系方式、“长期记住密码”开关会保存在 Chrome 的本地扩展存储中。只有当你主动开启“长期记住密码”时，安全密码才会一并保存在本地扩展存储中。

会话存储

未开启“长期记住密码”时，安全密码仅保存在 Chrome 会话存储中。订单查询的人机验证票据也仅保存在会话存储中。Chrome 会在浏览器会话结束后清除这些数据。

临时内存

订单列表、订单详情、卡密、验证码内容及查询过程中的状态，仅在扩展当前运行期间临时处理，不会由扩展另行写入持久存储。

重要提示：选择“长期记住密码”后，安全密码会以明文形式保存在该 Chrome 配置文件的扩展存储中。请仅在你信任且独占使用的设备和浏览器配置中启用此选项。

5. 浏览器权限说明

扩展仅申请实现上述功能所需的权限：

storage

保存商品显示偏好、联系方式，以及你选择保存的订单安全密码；同时在会话期间保存临时验证信息。

clipboardWrite

仅在你点击“复制”时，将单条或全部卡密写入剪贴板。扩展不会读取剪贴板内容。

https://wzyp.cn/*

在 WZYP 页面上整理商品、自动填写订单确认信息，并与 WZYP 接口通信。

https://*.wzyp.cn/*

在 WZYP 子域名页面提供相同功能，并处理由 WZYP 返回的订单与验证请求。

6. 数据共享与第三方服务

扩展没有自有后端，也不会把数据发送给扩展开发者。与订单、卡密或验证码相关的请求，由你的浏览器直接发送至 WZYP 网站接口或 WZYP 指定的验证码校验地址。这些请求可能包含：

  • 订单查询可能包含联系方式、临时验证票据，以及 WZYP 接口要求时的安全密码；
  • 读取卡密所需的订单号与安全密码；
  • 完成人机验证所需的验证码及校验信息。

除上述为实现你主动使用的功能而进行的通信外，扩展不会向第三方共享数据。扩展不包含广告 SDK、统计分析 SDK 或社交追踪器。

7. 数据安全

扩展通过 Chrome 提供的扩展存储隔离机制保存本地数据，并通过 HTTPS 与 WZYP 通信。卡密默认以遮罩形式显示，只有在你操作后才会显示或复制。

任何本地存储都无法保证绝对安全。如果设备、Chrome 配置文件或浏览器扩展环境被他人控制，本地保存的数据可能面临风险。请妥善保护设备，避免在公共或共享设备上长期保存安全密码，并在提交订单前核对自动填写内容。

8. 你的选择与控制

  • 你可以不填写联系方式或安全密码；相应的自动填写、订单查询或卡密查看功能将无法使用。
  • 你可以选择仅在当前浏览器会话中保存安全密码，而不启用长期记住。
  • 你可以在扩展设置中更改联系方式、清除密码或关闭相关偏好。
  • 你可以通过 Chrome 扩展管理页面清除扩展数据，或卸载扩展以删除其本地存储。
  • 复制到剪贴板的卡密由操作系统和其他应用管理；如有需要，请在使用后覆盖或清除剪贴板内容。

9. 未成年人

本扩展不是面向未成年人设计的服务，也不会主动识别用户年龄或故意收集未成年人的个人信息。如监护人认为未成年人通过本扩展提供了个人信息，可通过下述渠道联系我们。

10. 隐私政策更新

我们可能因扩展功能、权限或法律要求发生变化而更新本政策。重大变更会通过本页面或 Chrome Web Store 版本说明予以说明。更新后的政策将在标注的生效日期起适用。

11. 联系我们

如对本政策、扩展权限或数据处理方式有疑问，请通过“链动小铺助手”的 Chrome Web Store 商店页面所提供的开发者支持渠道联系我们。
